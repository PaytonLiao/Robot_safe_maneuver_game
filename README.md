# Robot Safe Maneuver Game

## Description

One of my most enjoyable technology projects is a 2D rescuing robot game developed solo in C. The game entails a robot rescuing people on an unknown planet, with increasing difficulty as more rescues occur—randomly spawning obstacles and potential speed boosts. Additional features, like the 'Big Mac' granting extra lives and the exhilarating **CRAZY mode**, added depth to the gaming experience.

The process of building the game, navigating testing and trial and error, brought immense satisfaction as it mirrored my envisioned outcome. This project taught me the core of programming—improvement through mistakes, emphasizing that coding proficiency comes with practice. I extend this philosophy beyond coding to general learning.

Continuing to enhance the game in my free time, I find joy in both playing and refining it. The project serves as a source of relaxation and entertainment, with ongoing updates, animations, and easter eggs enriching the overall experience. It's a testament to the gratification derived from creating, refining, and continually finding joy in technological endeavors.

## Features

- **Rescue People**: Navigate the robot to rescue people stranded on an unknown planet.
- **Dynamic Difficulty**: The game becomes more challenging as you rescue more people, with obstacles spawning randomly.
- **Power-ups**: Speed boosts and the 'Big Mac' item grant extra lives to help you progress.
- **CRAZY Mode**: An additional mode that increases the game's difficulty even further, offering a more intense gaming experience.
- **Animations & Easter Eggs**: Continuous updates with hidden surprises and engaging animations.

## Installation

To play the game locally, follow these steps:

1. Clone the repository:

    ```bash
    git clone <repository_url>
    ```

2. Navigate to the project directory:

    ```bash
    cd robot-safe-maneuver-game
    ```

3. Compile the C source code. Use a C compiler (e.g., `gcc`):

    ```bash
    gcc -o robot_game robot_game.c
    ```

4. Run the compiled program:

    ```bash
    ./robot_game
    ```

## How to Play

- **Move the robot**: Use the arrow keys to navigate the robot across the screen.
- **Rescue people**: Try to rescue as many people as you can while avoiding obstacles.
- **Collect power-ups**: Look for speed boosts and the 'Big Mac' for extra lives.
- **Avoid obstacles**: Randomly spawned obstacles will make the game more challenging.

## Technologies Used

- **C**: The main programming language used for the development of the game.
- **Graphics**: Simple 2D graphics to create a visually engaging experience.
- **Game Logic**: Randomized spawning of obstacles and power-ups to increase gameplay difficulty.
